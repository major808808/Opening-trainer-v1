# King's Indian Repertoire Trainer — Prototype 1

A small mobile-friendly prototype for practicing Black's King's Indian mainlines.

Included branches:
- Classical / Mar del Plata
- Sämisch
- Fianchetto
- Four Pawns

This first build focuses on validating the workflow. It uses a lightweight local opponent rather than Stockfish and simplified move handling. The next build should add a full chess rules library, Stockfish, PGN import, branching repertoire data, and eventually Lichess/Chess.com game import.

## GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md`.
3. Repository Settings -> Pages.
4. Deploy from the `main` branch and `/` (root).
5. Open the generated Pages URL on iPhone and use Share -> Add to Home Screen.
